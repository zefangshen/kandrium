Interface notes

Working notes for the visual pass. Density first, then colour.

Everything on screen should earn its contrast. A surface that only exists to group content gets a hairline, not a shadow. A control gets louder only while the pointer is on it, or while it holds focus.

Scale

The chrome sits at 12–13 px with 22 px line height. Reading text gets 14 px. Numerals, identifiers and dates are set in mono so columns of numbers line up without a second alignment pass.

  • Column title: 12.5 / 560, count in mono at 9.5
  • Card title: 13 / 500, meta at 10 mono
  • Section headings: 17 / 600, tracking −0.012 em
